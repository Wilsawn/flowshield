# FlowShield Architecture

Document the 4-layer system:

1. User Experience Layer (passkey onboarding, consumer UI, operator dashboard)
2. Compliance Engine Layer (Cadence contracts: credential, action, agent, rule engine)
3. Zero-Knowledge Verification Layer (ZK verifier, client-side proof generation, trusted verifier bridge)
4. AI Intelligence Layer (regulatory radar, risk scoring, builder copilot, anomaly monitor)

Key principle: identity data never exists on-chain.
